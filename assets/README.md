# Audio assets

Audio files are not included in this repository. The game runs silently without them;
any file listed below that is present will be picked up automatically.

File names and their in-game keys are defined at the top of [`audio.py`](../audio.py).

```
assets/
├── Music/
│   ├── title_screen.mp3
│   ├── credits_true.mp3
│   ├── credits_win.mp3
│   └── credits_lose.mp3
├── Rooms/
│   ├── tomb.mp3
│   ├── tunnel.mp3
│   ├── beach.mp3
│   ├── cliffs.mp3
│   ├── church.mp3
│   ├── cellar.mp3
│   ├── town.mp3
│   ├── armory.mp3
│   ├── lab.mp3
│   ├── observatory.mp3
│   └── street.mp3
└── SFX/
    ├── laugh.wav
    ├── bats.wav
    ├── scifi.wav
    ├── item.wav
    ├── quit.wav
    └── icarus_impact.wav
```
